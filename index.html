01 / START

Three times, one run

See separate 0–100, 0–200, and 0–300 km/h times in the overlay as you accelerate.

Beat your best

Click Record again for another attempt. The app keeps a separate best time for each milestone.

How to use it

  1. Download and open the Windows app.
  2. Open Driving Empire in a window or borderless window. If the timer cannot see the speed, click Set speed area and select the large speed digits.
  3. Stop the car at 0 km/h and press W. The timer records each milestone automatically.

The app is unsigned, so Windows Smart App Control may block it on some PCs. The timer reads the speed shown on your screen; your display and game settings can affect detection.

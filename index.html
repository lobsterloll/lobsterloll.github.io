Field notes / Before you begin

A little setup.
Then you’re off.

01 / EXE

Open & go.

EXE downloads are Windows apps. Download the file and open it. Unsigned apps may show a Windows security warning.

02 / ZIP

Keep the crew together.

Extract the entire ZIP before launching. Leave the app, libraries, and assets in the same folder. Check the included README.

03 / SOURCE

For the curious.

Source downloads need a little setup. Follow the README to install Python and the project’s requirements. Some apps need extra hardware or drivers.

✳

These are personal projects and experiments. Expect a little setup, a little discovery, and the occasional rough edge.

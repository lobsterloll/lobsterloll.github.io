# P1 drivable prototype

Project root: `D:\chatgpt\Codex\unrealracinggame`. Engine: UE 5.8.3 at `D:\Workplaces\UE_5.8`.

## Controls

| Key | Action |
|---|---|
| W | Throttle |
| S | Brake; automatic reverse after stopping |
| A / D | Steer left / right |
| Space | Handbrake |
| C | Cycle Chase, CloseChase, Cockpit, Hood |
| R | Reset to the start point |

The pawn creates a transient Enhanced Input driving mapping context at possession. A separate UI context is reserved but inactive in P1. No input asset creation is needed in the Editor. The production Chaos Vehicles component has four template sports car wheels, an engine torque curve, rear wheel drive, automatic gears and auto reverse. The simple `L_P1Test` map has a wide flat pad, boundary walls and braking markers. The car mesh and physics asset come from Epic's installed UE 5.8 SportsCar template content under `Content/Vehicles/SportsCar` and are prototype art.

## Build

```powershell
$env:UE_SDKS_ROOT = 'D:\chatgpt\Codex\unrealracinggame\.toolchain'
& 'D:\Workplaces\UE_5.8\Engine\Build\BatchFiles\Build.bat' RacingMVPEditor Win64 Development 'D:\chatgpt\Codex\unrealracinggame\RacingMVP.uproject' -WaitMutex -NoHotReload
& 'D:\Workplaces\UE_5.8\Engine\Build\BatchFiles\RunUAT.bat' BuildCookRun '-project=D:\chatgpt\Codex\unrealracinggame\RacingMVP.uproject' -platform=Win64 -clientconfig=Development -build -cook -stage -pak -archive '-archivedirectory=D:\chatgpt\Codex\unrealracinggame\Packaged' -noP4 -utf8output
```

To regenerate the map if it is missing, run `UnrealEditor-Cmd.exe RacingMVP.uproject -run=pythonscript -script=Tools/CreateP1Map.py -unattended -nop4 -nullrhi` using absolute project paths.
